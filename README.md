# SDR Transceiver & DSP Labs (ADALM-Pluto)

Репозиторий с лабораторными работами, отчётами и программными реализациями приёмо-передающего тракта на базе программно-определяемого радио (SDR).

**Автор:** Волевач П. С. (группа ИКС-431, СибГУТИ, кафедра ТС и ВС)

---

## О проекте

Цель работ — последовательное построение и отладка цифрового радиотракта: от базовых схем приёма и передачи в GNU Radio до собственного приёмопередатчика на C/C++ и Python с цифровой обработкой сигналов (DSP) и визуализацией в реальном времени.

### Основные направления и функциональность
* **Среда GNU Radio:** построение моделей приёмника и передатчика, приём вещательного FM-сигнала, исследование аппаратных ограничений трансивера.
* **Низкоуровневая работа с SDR (SoapySDR / Libiio):** инициализация устройств, управление потоками и буферами, работа с представлением отсчётов АЦП/ЦАП.
* **Дуплексный обмен на двух платах ADALM-Pluto:** одновременная передача и приём IQ-отсчётов с разнесением частот (`TX`/`RX`),  запись сырых данных в бинарные `.pcm`-файлы.
* **Цифровая обработка сигналов (DSP):**
  * формирование и BPSK-модуляция/демодуляция текстовых пакетов;
  * согласованная фильтрация (свёртка) и выбор оптимальной фазы символьных отсчётов;
  * частотная синхронизация на базе петли Костаса (Costas Loop);
  * символьная синхронизация по алгоритму Гарднера.
* **Визуализация и анализ:** графический интерфейс на базе **Dear ImGui** для отображения принимаемых сигналов в реальном времени и навигации по записанным `.pcm`-дампам с помощью таймлайна.

## Зависимости и сборка

Для работы с платами ADALM-Pluto из кода на C/C++ требуются установленные библиотеки `libiio`, `libad9361-iio`, `SoapySDR` и модуль `SoapyPlutoSDR`:

```bash
mkdir build && cd build
cmake ..
make -j$(nproc)
```

После сборки библиотек следует запустить скрипт run.sh для сборки проекта:

```bash
./run.sh

```
Пример запуска двустороннего обмена с указанием режима работы (`tx` или `rx`) и URI устройства:

```bash
./main tx "ip:192.168.2.1" "Hello from TX"
./main rx "ip:192.168.3.1" "Hello from RX"
```
